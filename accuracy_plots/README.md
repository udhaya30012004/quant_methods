# FP8 PTQ Evaluation Plots — Quality, Accuracy & Model Size (`Qwen2.5-3B` on NVIDIA L4)

All 9 charts are generated by [`plot_accuracy.py`](plot_accuracy.py) in presentation order (for Speed & Latency charts, see `../time_plots/`):

1. **`01_ZeroShot_Benchmarks_Overview.png`** — Explains the 5 zero-shot benchmarks (16,695 total questions), BF16 baseline scores, and the tight FP8 score range.
2. **`02_Accuracy_BF16_vs_W8A16.png`** — Direct accuracy comparison: BF16 vs W8A16 (Per-Tensor & Per-Channel).
3. **`03_Accuracy_BF16_vs_W8A8_Dynamic.png`** — Direct accuracy comparison: BF16 vs W8A8 Dynamic (Per-Channel & Per-Tensor).
4. **`04_Accuracy_BF16_vs_W8A8_Static.png`** — Direct accuracy comparison: BF16 vs W8A8 Static (highlighting the HellaSwag drop).
5. **`05_Accuracy_All_Methods_Comparison.png`** — Zoomed 2×3 side-by-side accuracy comparison across all 6 methods for every benchmark.
6. **`06_KL_Divergence_and_Token_Agreement.png`** — Full-vocabulary Mean KL, P99 tail KL, FP16 noise floor, and Top-1 token agreement.
7. **`07_Loss_Curve_and_Perplexity.png`** — Real vLLM WikiText-2 Perplexity and window-by-window ΔLoss degradation curve (64 windows).
8. **`08_Head_to_Head_W8A16_vs_W8A8_and_PT_vs_PC.png`** — Direct head-to-head breakdown: W8A16 vs W8A8, Per-Tensor vs Per-Channel, and Dynamic vs Static.
9. **`09_Model_Size_and_Compression.png`** — Model checkpoint size in GB and ~45% compression across all FP8 methods.
